# Supplied 1.29 text dataset

85 original gzip-JSON book packs for 116 incoming editions. The maintained application remains Reader 2.0. The supplied legacy shell is archived under original-documents/reference-editions/parallel-reader-1.29 and is not substituted for the tested 1.28/2.0 shell.

Source USFM/display ZIPs are preserved byte-for-byte; complete RIGHTS.txt, DETAILS.html and PROVENANCE.json are also included in notices/ for offline distributions. No textual revision or pronunciation generation is performed. Each edition retains its own licence, including noncommercial/no-derivatives restrictions.
