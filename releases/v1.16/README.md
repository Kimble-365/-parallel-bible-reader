# Reader 1.16 — compact verses and clean copying

Removes the empty status paragraphs that reserved space above the first verse. The chapter's edition label remains once, without a Text 1 prefix. Individual verses no longer contain repeated translation headings or horizontal separators. Font controls and the existing top menu remain available.

Every displayed text passage has a chapter:verse prefix, also included in plain-text copying. KR33/38 inline source labels such as `{5:3}` become `5:3` at the corresponding source text. If a stored row contains both a psalm heading and the following native verse, both source passages appear on separate numbered lines. Other editions' ordinary text/braces are unchanged. Original files, source row IDs, saved text/index stores and existing link keys remain unchanged; this is a display/copy adapter, not a source-versification migration.

Selected text copied within the reading area excludes action buttons, notices and translation headings. Partial selections stay partial. The share/copy dialog includes the book name and numbered scripture text without the translation-name footer. Quotation provenance in the notebook remains intact. All 57 editions and previous media/export features are retained; this maintenance update adds no new text corpus. Source downloads and text payloads reuse the preceding releases.
