# Reader 1.23 — BHH texts and manuscript research

Adds three selectable text editions to the 77 inherited editions (80 editions in total, including concurrent English, Greek and LXXL imports): Samaritan Pentateuch (5 books, 5,841 records); Clementine Vulgate OT through THB (39 books, 23,480 records); MAM-simple Hebrew (39 books, 23,202 records). Source-local numbering, spelling and per-edition rights remain explicit. Matching numbers do not establish a critical verse alignment. No approved reconstructed BHH Bible is claimed.

[BHH source library](bhh.html) opens the full local ETCBC/DSS index: 500,995 source units under 997 source labels, with fragment/line locators and sign-level reconstruction, uncertainty, correction and removal annotations. Labels include composite and non-Qumran material. All units remain separate; this is not a synthetic DSS Bible. Orange flags reconstructed material; exact annotation arrays remain visible. The view includes paged filtering, source downloads and independent verified offline saving.

Four complete STEP TAHOT source files, 24 structured MAM book-group files, THB Hebrew/Greek lexicons and a research versification map are available as compressed source readers. The STEP files explicitly retain editorial retroversions/alternatives. THB/QDR are interfaces to overlapping primary sources, not independent witnesses. Existing WLC, Swete and STEPBible word-study resources are reused. All nine related repositories have a source entry and an honest import/availability explanation. DDHB publishes no ready corpus in its inspected tree; Tehillim is bounded research; the unlicensed modern Ginsburg digital edition is not redistributed.

The MAM converter dispatches known roles and fails on unknown types; it chooses combined cantillation once, keeps ketiv and qere, omits note prose/repeated endings from scripture, preserves exceptional letter text, and supplies separators/inverted nuns/implicit maqaf. Raw structured files retain distinctions simplified for display. This does not constitute complete Masorah commentary or a full MAM representation.

The build uses a normalized SQLite authoring database with FTS5 outside the publication tree, exports bounded gzip packs with SHA-256 manifests and reuses all previous payloads. Source input hashes and 32 Git blob identities are recorded. New text packs total 2,749,919 compressed bytes and DSS packs 11,771,676 bytes; the complete release size is reported after verification. Private user data/storage names and earlier release URLs remain intact. No automatic approval of scholarly conjectures or platform permissions is implemented.

Rebuild: acquire the exact source blobs recorded in `bhh-sources/provenance.json` into a source directory, then run `python tools/import_bhh_123.py --sources SOURCE_DIR --bhh BHH_DIR` and `python tools/wire_bhh_123.py`, then `python tools/merge_bhh_baseline_123.py` in a clean tree. No downloaded source code executes. Inputs/SQLite are local build data, not a browser dependency. Tests: `python tests/bhh_123.py` and `python tests/bhh_browser_123.py`. Chromium is the available browser; physical Safari/Edge and full linguistic review remain open.
