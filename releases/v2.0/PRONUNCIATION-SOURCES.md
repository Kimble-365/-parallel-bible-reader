# Separate Hebrew and Greek reading volumes

These volumes are reading aids in Reader 2.0, separate from the unchanged 84-edition main catalog. They are available in `reading-volumes.html`; select the named source, written Latin or pronunciation volume. Download one book or the complete source coverage as attributed UTF-8 text. The export identifies its source, method and limits. No speech recording is supplied.

## Sources and identities

- **WLC Hebrew / Aramaic:** the existing 39-book `hbo-wlc` source; Open Scriptures Hebrew Bible, CC BY 4.0. https://github.com/openscriptures/morphhb . The source's unusual letter sizes/suspended letters are typography, not extra letters. Ten installed rows contain apostrophe-serialized XML fragments from an earlier import. The reader parses only the known `l s="Hdigits"`, `/l`, `seg type="x-large|small|suspended"` and `seg` delimiters; every intervening letter, vowel, accent, maqaf and punctuation mark survives. Original source files and saved user texts remain untouched. New display, copy, Notes, search and PNG outputs use the corrected adapter. Exceptional lettering is rendered using plain text spans.
- **Delitzsch:** existing `heb-delitzsch-historical`, 27 books, historical Hebrew NT extracted from pinned Wikisource revisions; CC BY-SA 4.0. Original archive and exact revision manifest remain in `releases/v1.8/sources/heb-delitzsch-historical-delitzsch-wikisource.zip`. https://he.wikisource.org/wiki/הברית_החדשה . This is a Hebrew translation of the NT, not its Greek original or the latest revised Hebrew NT. Written Latin retains the installed ICU Hebrew-Latin 76 output.
- **Salkinson–Ginsburg:** separate eBible `hebsg` digital source dated 12 December 2025, retrieved 8 November 2026. https://ebible.org/hebsg/copyright.htm explicitly labels this source Public Domain. The downloaded archive contains 27 NT books and 7,957 numbered rows. It is not identified as the separate SDHS 2012/2018 revision. Original archive/member bytes, copyright and SHA-256 report are retained under `original-documents/reference-editions/salkinson-ginsburg/`. The derived JSON removes printed alternate verse-number markers, not words; the original numbering glyphs remain in USFM. No EPUB or mobile feed is modified.
- **Greek:** existing 27-book `grc-source` unfoldingWord Greek New Testament, CC BY-SA 4.0. https://git.door43.org/unfoldingWord/el-x-koine_ugnt . Modern pronunciation is applied to that same ancient wording, not substituted with a Modern Greek translation or labelled an ancient Koine reconstruction.

## Pronunciation method and limits

`pronunciation.js`, method `reading-estimate-1`, is an independently written, on-device rule adapter. Source identities, references and raw text are never rewritten. Its generated texts inherit the source's applicable attribution/share-alike terms; project adapter code is MIT. No external text/AI/font service receives user text.

**Israeli Hebrew** was explicitly selected by the user. The practical Latin key uses `sh`, `kh`, `ts`, `y` and the five vowel sounds `a e i o u`; `ʼ` separates represented alef/ayin. Stops versus fricatives use source dagesh. The aid handles shin/sin, shuruk, holam-vav, common vowel letters and final furtive patah. Vocal sheva uses a bounded heuristic; ordinary qamats defaults to `a`, explicit qamats qatan to `o`. Ambiguous qamats/sheva, names, lexical exceptions and stress need specialist review. Stress is not marked. Biblical Aramaic portions have not been validated as Israeli Hebrew. The divine name is read **Adonai**, or **Elohim** where the source has the hiriq cue; this is a documented reading convention, not an assertion of the ancient pronunciation. It is an estimate throughout, not a newly verified phonetic Bible.

**Modern Greek** uses `i` for η/ι/υ/ει/οι/υι, `e` for αι, `u` for ου; αυ/ευ/ηυ use `v` or `f` according to following voicing. The practical key uses `dh` for /ð/, `th` for /θ/, `gh` for /ɣ/, `kh` for /x/ and `y` for the voiced palatal fricative in front-vowel contexts. These digraphs are explained here rather than labelled strict IPA. Source accents become acute stress marks; breathing, vowel length and iota subscript are not pronounced. Diaeresis prevents vowel-pair combination. Modern double-consonant simplification and common consonant digraphs are handled. Lexical hiatus, palatalization, names, nasal-stop variation and connected speech can require manual review. No recording alignment or exhaustive linguistic verification is claimed.

## Apostolic Bible Polyglot disposition

Requested by the user, but **not publicly installed**. The publisher's text is linked at https://www.apostolicbible.com/text.htm . CrossWire records ABPGRK as copyrighted, with permission granted to CrossWire: https://www.crosswire.org/sword/copyright/ModInfoCopyright.jsp?modName=ABPGRK . That is not a redistribution/adaptation grant to this project. No complete ABP text or ABP-derived public pronunciation file is included. Public integration requires applicable permission from the rights holder. The page provides a general private text-to-reading-file converter for text the user may use; it neither uploads text nor asserts ABP permission.

## Offline and storage

WLC, Delitzsch and Greek volumes reuse the existing saved-source store; source/derived views do not duplicate or migrate it. Salkinson uses a separate checksum-bound cache and verifies each book's bytes before saving. The shell is service-worker cached, with an explicit save action for source coverage. A download alone is not an installed PWA. Browser/host/port changes still create a separate storage origin. No existing notes, bookmarks, highlights or main-reader slots are edited by this page.

## Additional ABP copyright check

The publisher's own introduction copyright page (PDF p. 4, printed iv) states copyright 1996 and 2013, Charles Van der Pool, all rights reserved; first publication 1996, second edition 2013. The publisher offers free PDF access but does not thereby grant this project full redistribution/adaptation rights. No expired/public-domain ABP edition was located in the checked publisher, CrossWire and STEP records.

The introduction identifies historical Aldine/Sixtine printed sources and Lambert Bos's 1709 edition; these are independent works, not earlier public-domain ABP editions. A concrete public-domain image lead is NYPL's Complutensian Polyglot spread (printed 1514–1517), whose item page marks it free to use and explains its US public-domain assessment: https://old-digitalcollections.nypl.org/items/899001eb-0c64-394f-e040-e00a18065714 . This is a scanned spread, not a verified complete machine-readable Bible. It is linked externally and has not been imported or OCR-reconstructed.

For an already usable separate ancient Greek OT source, the reader offers the installed **Swete Septuagint** and a Modern Greek reading estimate of that same text. Its 52 installed source books exclude Ecclesiastes; the license and metadata remain unchanged (CC BY-SA 4.0 digital-source notice). The historical print is distinct from the digital transcription and from ABP's eclectic text, English interlinear and AB-Strong system. No ABP-equivalence claim is made.
