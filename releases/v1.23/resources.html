Bible apps & reusable text sources

Research checked 2026-10-28 using provider pages and documentation. These are design ideas and text-source candidates, not claims that all features/texts are installed. Actual provider playback/account flows were not exercised. The reader stays account-free and keeps the main screen simple.

Text candidates

No new full Bible is bundled by this research. The public catalog remains 62 editions.

Candidate/sourceRights evidenceNext acquisition check
Japanese Kougo-yaku 1954/1955CrossWire module JapKougo labels this historical colloquial edition Public Domain.High-priority Japanese candidate. Acquire the exact module/readable export, verify coverage/source numbering, then create separate kana/Latin aids. Not Shinkaiyaku 2017; not installed by this research.
Berean Bible / Berean Standard BiblePublisher dedicates Berean and Majority Bible texts to the public domain from 30 April 2023.High-priority modern English candidate; pin a source download and validate any verse annotations. Text dedication does not automatically prove every recording is reusable.
unfoldingWord ULT/UST and language projectsPublisher describes the listed resources as CC BY-SA 4.0.Possible literal/simplified text pairs, plus new regional languages through Door43. Verify the exact language project, release, canon and attribution before acquisition. OBS is a retelling, not a Bible translation.
STEPBible original-language datasetsRepository states CC BY 4.0; individual files/resources need attribution checks.Tagged Hebrew/Greek, lexicons and word-level data can support optional word study. Do not silently replace the installed source editions or claim all external texts share this license.
eBible.org and Open.BibleEdition-specific Public Domain/Creative Commons notices; coverage varies.Strong sources for licensed Asian, African, European and minority-language USFM. Deduplicate installed 62 editions and check actual source coverage instead of treating catalog descriptions as complete Bibles.
Free Use Bible APICatalog provides each translation’s license URL and book counts; structured and simplified formats.Useful acquisition/index adapter candidate with explicit edition metadata. Review source/license per translation, preserve source hashes, headings, notes and unusual numbering. No blanket permission is inferred.
API.Bible / Digital Bible LibraryOpen and protected versions have separate agreements and access terms.Possible later approved integration. Not a permission to scrape protected texts, expose an API key or republish every translation.

Recommended order

  1. Ship and verify aligned verses, local gzip decoding and optional kana aids.
  2. Ship simple original multi-passage reading paths with manual progress.
  3. Acquire Japanese Kougo-yaku and Berean text from pinned reusable sources, with source archives and integrity tests.
  4. Add optional saved reading sets, verse highlights and lightweight word/cross-reference help behind menus.

Full Estonian OT, further guide translations and linguistic review remain open. Audio-synchronized highlighting requires verified timing data. No encyclopedia, copied proprietary interface/assets, publisher plans or automatic account integration is included.
