# WLEXPACK version 1

A deterministic ZIP archive with two ordered entries: `manifest.json` (stored UTF-8 canonical JSON), then `book.sqlite` (DEFLATE level 9). ZIP entry timestamps are 1980-01-01 00:00:00; Unix creator, mode 100644; no comments, encryption, data descriptors or ZIP64. Integer fields use normal ZIP little-endian layout. Browser decoding is bounded Pako raw-DEFLATE, followed by the existing read-only SQLite table reader. No runtime SQL or WASM download is needed.

The external `CODE.manifest.json` adds `packed_sha256`, `packed_bytes` and the pack URL. The embedded manifest never includes a hash of the enclosing archive. Both declare format/version/schema, canonical reader book code, source revision and SHA-256, SQLite SHA-256 and exact byte length, payload name, codec, license summary, fingerprint, verse count, independent coverage counters and research status. `packs/manifest.json` is the discovery catalog; it additionally identifies verified comparison sidecars. Payloads must be verified against the external manifest before SQLite access. Hashes establish integrity relative to that manifest, not independent authenticity.

`schema.sql` is the version-1 migration baseline (`PRAGMA user_version=1`). Unknown schemas are rejected with a rebuild message. No destructive or automatic in-browser migration is attempted. Future migrations need fixtures before a version bump.

Occurrence IDs are `oshb:REVISION:OSIS_VERSE:POSITION:0`; morphological segments use the same prefix with a positive final segment number. Position enumerates direct source words and separately encoded note-reading words in source element order. Main/ketiv/qere/alternative identities are distinct. A qere is linked only to the preceding explicit ketiv in its note context; an unmatched qere stays unaligned. No identity is keyed by spelling. Source XML word IDs, raw lemma and morphology, source-language tags and exact unnormalized forms are retained. Segment lemma/morphology mismatches remain NULL instead of receiving guessed alignments. Language uses the source morphology prefix; untagged words remain `und`.

Each book contains its own lemma records and sources. The importer preserves the full source file as deterministic gzip bytes and byte-addressed exact XML for every verse. Auditing compares every stored verse slice to the pinned input and every projected display event to the displayed text, with codepoint offsets verified for token buttons. The reading projection hides only OSHB slash segmentation and XML formatting indentation, shows direct w/seg elements, joins maqaf without spaces, and retains ketiv while offering qere separately. Notes are not silently substituted into the main text. The projection is not a claim of byte identity with an independently typeset WLC display.

Build fingerprints include source, schema, builder, dictionary and selected research hashes. Acquisition timestamps belong in the external acquisition ledger so repeated identical inputs produce identical databases and packs. Reproducibility is tested within the same Python/SQLite/zlib toolchain; compressed byte identity across library versions is not promised. A checkpoint is adopted only if its fingerprint and current SQLite hash match and the database passes a fresh audit.

Comparison files are canonical JSON compressed with deterministic gzip. Compressed and expanded hashes and lengths are verified separately. Each includes edition IDs, source strings and labels, input-asset hashes and the pinned maintained reader revision. LXXL research records retain their reported evidence class and source locators. These do not populate reviewed contextual senses.

Current codecs are ZIP DEFLATE and companion gzip only. Brotli and Zstandard are deferred until measured cross-browser benefit warrants another codec; there is no unsupported codec fallback.
