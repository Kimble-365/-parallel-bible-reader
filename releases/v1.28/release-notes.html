Parallel Bible Reader 1.28

Prepared as a review package. The production website remains unchanged until publication is separately approved.

What is included

  • Six reading fonts with Unicode and script fallbacks.
  • Select a verse for Copy, Notes, Bookmark, Share and color highlights.
  • Local PNG verse images and comparison of the selected translations.
  • Bible, theology and salvation introductions; eight original and three attributed historic prayers, with Pray from a selected verse.
  • The existing 84 Bible editions, discovery, reading and study features. Coverage and numbering remain specific to each edition.

Offline package

The verified ZIP is attached as the reader-1.28-review-package artifact to its successful project check run. Downloading this review artifact may require a GitHub sign-in. It is not a public GitHub Release.

Extract the whole ZIP and run python3 START-READER.py (Windows: py START-READER.py). Python 3 is required; no extra packages or account are needed to read the included texts. Keep the folder structure and local server running.

Direct opening from Files uses a file:// address and is restricted by browsers. For full functionality use the included local server on a desktop, or a separately approved HTTPS/PWA publication on iPhone/iPad. External audio/video and source-hosted study materials may still require Internet.

Your saved data

The application keeps its existing store names. A local server and GitHub Pages have different browser storage origins. Export Notes and vocabulary backups before transfer; keep using the same local address and port for local sessions. Building or extracting the package does not overwrite your saved notes, highlights or bookmarks.
