Textual apparatus

Return to reader 1.23

Study → Textual apparatus is an independent source reader. It does not silently align apparatus numbering with Text 1, change the Bible text or reconstruct an original reading. A missing entry does not imply witness agreement. Filters and previous/next buttons follow the references actually recorded in the source.

Sources included as optional loaders

  • SBLGNT: apparatus XML for 27 NT books, pinned by commit and Git blob checksum. Michael W. Holmes, editor; © 2010 Society of Biblical Literature and Logos Bible Software. CC BY 4.0. Notes are preserved as printed-edition comparisons, not converted into manuscript support counts. Consult the source introduction for its sigla and symbols. This is not NA28/UBS5's complete manuscript apparatus.
  • Open Scriptures Hebrew Bible: variant/qere/ketiv notes in 39 WLC book files. Original work of the Open Scriptures Hebrew Bible Project. WLC text is public domain; annotations CC BY 4.0. Source catchwords, reading labels and Unicode sequences are retained. This is not a full BHS/BHQ apparatus or a collation of all Hebrew witnesses.
  • LXX and Syriac: device import supports the same reader. No full Göttingen, Cambridge or Leiden apparatus is bundled. Plain biblical texts are not substitutes for apparatuses. ETCBC's Peshitta notes explain that its public base-text repository excludes the printed critical apparatus. Helsinki's Septuagint data project is a research lead, not an installed corpus here.

Load a source book only when requested, then choose Save source book offline to keep its checksum-verified raw bytes on this device. Source downloads are separate from private imports. The Study library's saved-pack list can remove downloaded source books. Installed Bible editions, notes and vocabulary are unaffected.

Private imports

Choose a UTF-8 JSON, JSONL or TEI-XML file, optionally gzip-compressed. Maximum input and expanded text: 4 MiB; maximum 12,000 entries. Preview first, then explicitly save. Up to 10 private packages / 24 MiB are stored in a separate IndexedDB database. Private content is not uploaded or added to this public site. Export JSON before moving browser/device or removing an import; browser storage can be cleared or evicted.

JSON packages declare their own tradition. For JSONL/TEI, choose the tradition and optional title before choosing the file. Changing these controls clears the preview; choose the file again. Only import material you may use. Import does not grant redistribution rights. The original research record/XML remains available beneath each entry; statuses and proposals are displayed without adoption. A source hash in an imported record is a provenance claim, not proof independently checked by this reader.

Native JSON format

Use greek-nt, lxx, hebrew or syriac. The following is a synthetic format example, not evidence for any historical reading. Replace it with source-backed records and correct attribution.

{
  "format": "parallel-reader-apparatus", "version": 1,
  "family": "syriac", "title": "FORMAT EXAMPLE — NOT HISTORICAL EVIDENCE",
  "source": "Synthetic example", "license": "Example only",
  "witnesses": {"EXAMPLE-A": "Synthetic siglum, not a manuscript"},
  "units": [{
    "id": "example-1", "reference": "GEN.1.1",
    "lemma": "ܐ", "lemmaWitnesses": ["EXAMPLE-A"],
    "readings": [{"text": "ܒ", "witnesses": ["EXAMPLE-B"], "note": "Synthetic reading"}],
    "note": "Not historical evidence", "status": "format-example"
  }]
}

Research JSONL / record arrays

One object per line, or a JSON array. Reference may be reference, address or locus. Supported readings use reading/text or display_tokens[].form; support may use source_siglum or supports[].witness_id. The complete original object is retained, including hand labels, source locators, transcribed text, editorial normalization flags, rights and evidence status. Printed comparison editions are labeled separately. Evidence arrays are shown as source/version evidence, not automatically as variants of the lemma. Omission strings and stars are not expanded into inferred readings or manuscript identities. Draft/unapproved decisions remain draft/unapproved.

TEI subset

TEI critical apparatus: inline app with zero or one lem, direct rdg and note, wit references and optional hand/type/resp. Reference must be on app loc="Gen.1.1" or an enclosing ab n="Gen.1.1". listWit/witness xml:id definitions are displayed; unresolved IDs remain unresolved. All four scripts are accepted. Lemma-only draft notes are supported. Text display is a projection: inspect the retained original XML for supplied letters, gaps, unclear readings and other markup. No Unicode normalization or inferred pronunciation is applied.

Nested app, rdgGrp, stand-off from/to links, external entities and document type declarations are rejected for explicit conversion, rather than silently flattening their structure. This is not a general-purpose TEI renderer. Scanned apparatus PDFs/OCR and SQLite databases need a separate verified extraction/conversion step.

Reading responsibly

Keep an edition's local sigla and corrector labels in their own namespace. A versional parallel is not an independent Greek manuscript; a restored DSS passage is not necessarily preserved text; two printed editions are not two independent witnesses. Review original records, sources and licenses. A technical import or passing software test does not establish textual-critical accuracy.
