## Page navigation

Settings → Reading appearance → Page navigation enables page view in aligned reading. Previous/Next page, Page Up/Down and horizontal swipes move through a bounded reading viewport; chapter boundaries continue through the existing reader navigation. Page segments overlap slightly so the boundary never silently omits text. Scroll/pinch/selection remain available. Paper turn, gentle fade or no animation are selectable; prefers-reduced-motion disables animation. Independent source chapters retain scrolling. This is an original CSS/DOM implementation inspired by NET’s page navigation, not copied app code/assets.

## Word study and literary reading

Study → Word study & vocabulary pairs original words, optional written transliteration and English glosses. Hebrew runs RTL and Greek LTR. Tap for source word/morphology codes and save words for local flashcard practice; search within the verse by word/transliteration/gloss/code. Practice can use one verse or saved words; meanings are revealed manually and vocabulary exports as attributed JSON. This adapts Literary Rendition’s original-word/meaning/practice idea, without copying its poems or recordings. Source transliteration is not a phonetic transcript or verified spoken form. Existing listening links remain separate; no word audio is invented.

The optional dataset is TAGNT/TAHOT from STEPBible.org / Tyndale House, Cambridge, adapted to JSON by GabeBrPierce, CC BY 4.0, pinned commit 2076684f9200eb1b119aa7effbf58f9ec571c0ca. The local catalog indexes 31,219 source verse files across 66 books with immutable Git blob hashes and declared lengths. This counts source files, not verified equivalents to every installed translation. Data loads only when requested; source order, morphology, glosses and references are preserved. Analysis slashes/backslashes are omitted from displayed original words, while exact source tokens remain in details, saved records and exports. Save a verse/chapter for offline use; partial saves can be stopped/resumed. The index/shell works offline after initialization; unsaved remote packs remain unavailable offline. No universal pronunciation, contextual gloss review or full corpus semantic validation is claimed.

## Library and study notes

Study → Library & study notes has 60 entries from the supplied screenshots plus NET/offline-Bible links. Categories cover commentaries, dictionaries, concordances, encyclopedias and church history. Each entry identifies an in-app source or external provider access. Modern ESV/Wiersbe/CSB/Holman/Applied and other protected/uncleared editions remain provider-hosted. NET translator notes open the official publisher site; the complete protected notes are not republished. Personal notes are unchanged and distinct from author commentary.

Eight resources have real on-demand source readers: Matthew Henry complete-work snapshot, Henry concise chapter files, John Gill, Jamieson–Fausset–Brown, Wesley, Easton, Smith and Hitchcock. These are source snapshots with gaps/transcription defects, not claims that every edition/entry is complete. The complete-work Henry/Gill/JFB manifests each have 65 source book packs, Wesley 63; Henry concise has 1,038 chapter files. Dictionary packs are alphabetic and only letters present in the source are offered. Read a selected book/chapter or dictionary headword, then explicitly save the pack on this device. Saved-pack removal is separate from Bible texts, notes and vocabulary. Source English text is preserved; generated summaries are not displayed.

Historical commentary text is public domain as recorded per file. OpenChristianData source conversion/metadata is attributed with its repository’s noncommercial metadata/tooling conditions retained; this reader’s distribution is noncommercial. Henry concise Markdown source is CC0. NEUU dictionary data is CC BY 4.0 with historical CCEL source credits. Every remote pack is pinned and length/Git-hash checked before display or retention. These optional corpora are hosted upstream and saved locally instead of exceeding the Pages site budget. Corrupt, incomplete, unsupported or missing packs produce a visible error, never invented notes. Whole-commentary/whole-interlinear automatic mass downloads are not performed on page load.

The Bible catalog remains 62 editions; study datasets are a separate source layer. Earlier full Estonian OT, other translated guides and linguistic-review items remain open. Physical Safari/iOS page effects and assistive-technology trials remain unverified until tested on those devices.
