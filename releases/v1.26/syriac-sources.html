What changed in display

TF source forms and source trailers are joined; trailing whitespace is removed. TEI indentation/whitespace is collapsed within verse elements without normalizing Syriac letters or combining marks. No consonants, vowels, translations or readings are generated. Source A/B versions retain distinct book keys. Some source units contain only markers and remain identified as such in source study. Discontinuous TF verse spans retain their slot ranges; they are not manuscript lacunae. Some morphological segments have no surface form in the source; the study view shows ∅ without supplying letters.

The DSC Luke file has two different units labeled 11:42. Both are retained under that source label, with an explicit warning and separate XPath occurrence locators. The first resembles a differently numbered passage, but no correction is asserted here. Source numbering is not proof of cross-version passage equivalence.

Shared lexical data and storage

5,022 unique source lexeme–English-gloss entries are stored once in 16 compressed shards. Occurrence records reference IDs and retain source morphology, token offsets and stable source node IDs. The lexeme transcription uses the ETCBC scheme; it is not a pronunciation guide. Reading packs load only for the selected edition/book. Analysis indexes and lexical shards load on demand. Save selected texts retains reading text on this device; word analysis requires a connection unless already in current-session memory. No Finnish interlinear or new critical reconstruction is claimed.

Other surveyed projects

Sycgloss informs separation of prefix parsing, notation and gloss presentation; no SEDRA payload or PHP code is copied. peshitta-tools and ETCBC/syrnt remain NT analysis candidates: altered-file redistribution restrictions in SEDRA III require clarification, independent of the conversion-code license.

CollateX is an optional GPL-licensed collation tool, not a Bible text. The project supplies an alignment-input exporter; it does not claim CollateX was run or that it selected critical readings. Digital Wright supplies a manuscript-catalogue reference model; its archived predecessors are not used as current data. Catalogue statements are not image-verified readings.

Syriac Parallel Reader informs pinned source locks, lazy occurrence indexes and separate data/code rights. This reader imports directly from pinned upstream datasets, without copying that project's corpus copies. AudoDigitization informs preservation of source entry order and explicit diacritics; its dictionary is not bundled because reuse rights remain unverified. Peshitta Transmuter remains a script-conversion reference; its CAL permission claim does not authorize our derivative redistribution. No duplicate CAL text or speculative transliteration is included.

Apokryfikirjat remains a candidate Finnish interlinear reference. No Finnish text or glossary has been copied. Research project and critical-edition model.
