# Reader 1.10 — Finnish Biblia 1776 and private Finnish edition imports

44 publicly installed text editions: adds Finnish Biblia 1776 (78 nonempty source books / 35,445 numbered units, including the source’s historical additional books) to the 43 editions in 1.9. Native numbering is retained with independent source panels. FinBiblia declares Public Domain; original JSON, proof, checksum and derived UTF-8 USFM are in sources/. The authoring SQLite source-unit table and FTS include this edition.

Open **Finnish Bibles — Suomenkieliset Raamatut**. Biblia 1776 is included and can be selected beside KR33/38. The new text supports directory/favorites, all four slots, search, sharing and selected-text offline saving.

KR92, Raamattu Kansalle and LLL have publisher links and private-device import choices. Their full texts are not bundled in the public repository. KR92’s owner and Raamattu Kansalle require separate permission for redistribution beyond their personal-use allowances. LLL’s publisher permits personal downloading/storage; a public redistribution license was not verified. The user supplied a specific LLL.zip, containing LLL.ont, for this integration. That private source file and its converted text are not committed to GitHub.

To use your permitted LLL copy, download LLL.zip from the link in the panel, select **LLL**, choose Text 1–4, choose the ZIP file and press **Import to this device**. Browsers supporting raw-deflate decompression can open the ZIP directly. Otherwise extract it and choose LLL.ont. For KR92/RK choose your own permitted matching theWord .ont file. PDF, e-Sword SQLite and SWORD module import are not implemented. The importer checks the edition description, UTF-8, the standard 31,102 reference slots, ZIP size/CRC and supported markup. It does not download protected texts automatically or upload your file.

An imported edition becomes available in the slot controls and directory after reload, with source text, search and offline access. Imports replace the same private edition atomically, including completion metadata. Personal data is stored only in this version’s IndexedDB; another browser/device or recipient of a shared link needs their own permitted import. Removing a private copy removes its local catalog registration and reloads; stored bookmark records are not erased. Browser storage eviction/site-data clearing can remove private imports, so keep your original file. The 1.10 database is separate from 1.9’s experiment; earlier saved texts are not automatically migrated.

The plain reader removes tagged headings and notes, including LLL’s nested heading structures, but does not rewrite source scripture words or reconstruct undocumented formatting. Unmarked source text remains text. The fixed reference counts are numeric facts cross-checked against BibleMultiConverter’s standard KJV map, with provenance in sources/ont-map-provenance.json. No Java implementation code is copied. There is no claim that every translation’s source numbering is aligned semantically.

PWA shell is scoped only to releases/v1.10. Existing editions reuse verified 1.8/root sources; Biblia 1776 has its own small book files. Audio and publisher/download sites need internet. The file-open ZIP remains the explicitly labeled 1.8 package; it does not contain the new 1.10 features.

Tested with real 1776 text and the user-provided LLL ZIP in Chromium: third-slot import, 66-book mapping with John 3:16 and Revelation samples, directory, offline reload/search, plain ONT and wrong-edition rejection, and no POST upload. Existing four-slot/storage/theme/mobile behavior is regression-tested. KR92/RK import paths are format support, not a claim to possessing or testing their actual protected text files. Safari/Edge/physical device installation remains untested.
