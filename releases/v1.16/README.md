Selected text copied within the reading area excludes action buttons, notices and translation headings. Partial selections stay partial. The share/copy dialog includes the book name and numbered scripture text without the translation-name footer. Quotation provenance in the notebook remains intact. All 57 editions and previous media/export features are retained; this maintenance update adds no new text corpus. Source downloads and text payloads reuse the preceding releases.
