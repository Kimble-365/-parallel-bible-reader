# Reader 1.6 — pronunciation adapter pilot

Retains the 1.2–1.5 features and adds a common versioned adapter registry for written-script and pronunciation forms. WEB English has an optional US English phoneme estimate derived from CMUdict, loaded only when requested. It covers 740,906 of 757,247 WEB word occurrences (97.84%); 9,186 of 12,586 distinct spellings.

This is an experimental broad phonemic aid, not a natural colloquial translation, speaker-reviewed transcript or narrow phonetic transcription. Stress and syllable boundaries are omitted. The first dictionary reading is used; 1,131 matched words have multiple dictionary readings. Unknown words remain as ⟦source⟧. Original WEB remains available unchanged. Other languages do not acquire an invented spoken form.

Each slot's form survives sharing, browsing and local-state restoration. Visible-form search includes the chosen estimate, while hidden forms do not contribute matches. Urdu written-script choices remain independent. Source licenses and pronunciation resource metadata are bundled.
