# Reader 1.17 onward — staged delivery contract

Requested 2026-10-27; adds CrossWire to the requested sources.

1. **1.17 — approachable study menu.** Reading history, a dated daily reading plan, presentation mode, one reader-version label at the start, and a combined Contents & introductions menu. Keep the reading page uncluttered and previous clean-copy/native-reference behavior intact. Separate Indo-Iranian browsing from other Indo-European branches without denying that Indo-Iranian is part of Indo-European.
2. **Nordic text packs.** Swedish 1917, Norwegian Bokmål 1930, Norwegian Nynorsk 1921, Icelandic and a complete licensed Estonian text. Verify the exact source, scope and license independently. Do not relabel the old unknown-license Est module as open. Keep the existing five-book modern Estonian snapshot until a complete matching source is verified. Store further corpora outside the already near-limit Pages deployment and pin immutable pack revisions/checksums.
3. **Private-device imports and provider adapters.** Crossway, e-Sword, Bible Hub, Bible.is, YouVersion, STEP Bible, Davar, CrossWire and other documented export formats. Implement actual parse/preview/install paths for supported files; show exact limits for encrypted/proprietary modules and authenticated providers. Never substitute a list of links for implemented import support. Never claim permission for all content on a service from one open module's license. Keep user files and keys off public GitHub.
4. **Non-Latin reading forms.** Preserve original text and written transliteration. Japanese needs a separately labeled automatic dictionary reading for kanji, with unknowns and linguistic-review limits visible; do not call kana-only conversion a complete romanization or spoken transcript.
5. **Contents, headings and introductions.** One menu for these materials, with source/translator attribution, language selection, native source headings where available, translated reader guides and explicit fallback labels. Editorial content is separate from Scripture. Translation coverage must be counted and honestly reported; unsupported-language guides must not masquerade as translated material.

Previously proposed menu additions mean **reading history, daily reading plan and presentation mode** (1.15 README). Provider API credentials and redistribution rights are distinct from technical format support. An account-free static app can import permitted user exports; protected live services require their supported authorization mechanisms.

All increments retain numbered URLs, notes, saved texts, four independent slots and original sources. Use GitHub Actions for actual browser checks because local socket execution is restricted. Publish/promote after checks; verify the deployed file hashes. No Bible Encyclopedia material.
