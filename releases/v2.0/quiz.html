How to host with phones

On the host computer, start the supplied START-QUIZ.py --lan launcher. In a source checkout, use python tools/local/quiz_server_20.py --lan. Open the displayed address. Players use the computer's local-network address and the same port. Guest Wi-Fi may block device-to-device connections.

This is a temporary local-network game, with up to 32 players. No account or cloud service is used. The host must keep the launcher running. Internet hosting is not configured.
