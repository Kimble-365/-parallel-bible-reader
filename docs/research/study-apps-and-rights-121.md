# Study-app adaptation and source rights — 1.21

Identified App Store sources: Literary Rendition (World Poetry with Audio, id6444036634), NET Bible/Formerly Lumina (id687558432), and an Interlinear Bible app (id1386148836) matching the described Hebrew/Greek/transliteration features. The generic app name “Bible” is not a unique identification; the user can supply its exact link while implementation uses the requested functional idea. Public descriptions were inspected; proprietary app binaries, source code, screenshots, content layouts/assets and audio were not copied.

Literary Rendition motivates original text + brief word meanings + optional help + per-verse vocabulary practice. NET motivates optional page navigation, accessible motion choices and contextual study notes. NET’s full translator notes require separate permission (see https://www.stepbible.org/version.jsp?version=NET2full and https://bible.org/article/trademark-and-copyright-information); link to https://netbible.org/ rather than bundle protected notes. Existing personal notes remain separate.

The user’s screenshots identify BibleStudyTools dictionaries, commentaries, concordances, encyclopedias and history. Their catalog titles are listed in an original UI with original access descriptions; protected/uncleared editions link to provider indexes and do not become freely redistributable merely because an app displays them. Official index pages: https://www.biblestudytools.com/commentaries/ , /dictionaries/ , /concordances/ , /encyclopedias/ , /history/ . The newest explicit request includes optional encyclopedia resources; this does not reintroduce the older unrelated Biblical Encyclopedia product into the reader’s default view.

A different OCD Hitchcock export explicitly recorded pending confirmation for its digital source; that export was not selected for the reader.

Raw packs are fetched only by explicit study actions, from immutable raw.githubusercontent.com URLs. Git blob SHA-1 identity plus length limits are checked; local indexes have SHA256 manifests. No raw HTML is executed. Device packs use a distinct IndexedDB store and are verified again when read. Data source outages/blocks remain possible; explicitly saved packs work offline. Offline Bible links include the existing selected-text saver plus official BLB/CrossWire/AndBible/e-Sword/eBible sites.
