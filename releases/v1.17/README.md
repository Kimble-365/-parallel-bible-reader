# Reader 1.17 — study tools and language grouping

This staged increment adds **Study** (reading history, a seven-day dated reading plan and presentation mode) and **Contents** (book introductions and chapter navigation) to the top menu. The reader version appears once at the beginning of the reading area. Verses retain the clean-copy and native-reference behavior of 1.16.

History retains at most 100 chapter/display choices on this device and can be cleared. Plan completion is manual and persists across reloads; opening a chapter never marks it read. Unavailable plan readings are disabled for Text 1. Presentation uses the current Text 1 display, supports previous/next and arrow keys, and offers optional browser full screen. All panels use local storage only; private notes are unchanged.

The directory has a Subfamily / branch filter. Indo-Iranian is shown separately inside Indo-European, with the existing Indo-Aryan editions under that subgroup. Finnish remains Uralic. No competing or invented language-family classification is implied.

The existing English reader summaries are collected in the Contents menu. They are editorial guides, not the original translation's prefaces. Translation of these guides, native source headings/outlines and additional language packs are subsequent stages; the menu explicitly identifies English fallback rather than pretending all languages are translated.

Requested Nordic texts, improved Japanese reading and general provider imports are tracked in [the next-stage contract](../../docs/research/next-stages-117.md). This increment does not claim those later stages are installed. Browser verification runs before promotion; physical Safari use remains untested.
