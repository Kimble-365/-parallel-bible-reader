# Reader 1.24 — source-aware textual apparatus

Prepared increment; integration browser verification and publication remain pending. Earlier apparatus checks passed on the older baseline; the current release requires its own combined run.

Study → Textual apparatus opens a separate source reader for Greek NT, Greek OT/LXX, Hebrew and Syriac. Search loaded readings/notes/status, filter source references and exact witness sigla, navigate previous/next recorded references and export an attributed JSON package. Right-to-left and mixed-script readings use Unicode direction isolation; no NFC/phonetic reconstruction or manuscript-identity guessing is applied.

Optional live loaders: SBLGNT apparatus XML for 27 NT books (printed-edition comparison, not the NA28/UBS manuscript apparatus) and OSHB WLC qere/ketiv/variant notes for 39 Hebrew books (not full BHS/BHQ). Immutable source manifests specify commit, size and Git blob checksum. Save a source book separately for offline use. No source downloads run merely by opening the reader. Exact open Philemon/Ruth fixtures verify byte identity and parsing.

Private JSON/JSONL and restricted TEI apparatus import supports all four traditions, including research records using reference/address/locus, display_tokens/supports, source_siglum and evidence arrays. Original objects and XML are retained for inspection. Printed edition comparisons, manuscript hands, source/version evidence, statuses and unapproved proposals remain distinct. TEI preserves witness definitions and header/rights, and rejects nested/grouped/stand-off apparatus that needs explicit conversion. This is a reader, not a scholarly collation or full generic TEI engine.

Preview then explicitly save to a separate device-only IndexedDB library (up to 10 imports / 24 MiB). Input and expanded text are bounded at 4 MiB; gzip uses the existing local fallback. Private imports are never uploaded, copied into the public repository or fetched from private GitHub by browser code. Export JSON before removing an import or changing device. Unsupported/corrupt files do not replace earlier imports. No private source records are used in public tests; format fixtures are synthetic and clearly labeled.

LXX and Syriac apparatus display is ready for permitted imports; no full modern Göttingen/Cambridge/Leiden corpus is bundled. Open base texts are not mislabeled as critical apparatus. Empty results do not imply agreement. Source numbering is retained, with no automatic equivalence claim for Text 1. The current 1.23 baseline and its 80 selectable editions, BHH manuscript/source library, NTGL/LXXL and related texts are retained. Large BHH payloads are reused from 1.23; all prior device storage keys are preserved.

See [formats, provenance and limitations](apparatus-guide.html). Physical Safari/Edge script-font and interaction review remains open; no claim of exhaustive textual-critical validation is made.

## Retained BHH scope


Adds three selectable text editions to the 77 inherited editions (80 editions in total, including concurrent English, Greek and LXXL imports): Samaritan Pentateuch (5 books, 5,841 records); Clementine Vulgate OT through THB (39 books, 23,480 records); MAM-simple Hebrew (39 books, 23,202 records). Source-local numbering, spelling and per-edition rights remain explicit. Matching numbers do not establish a critical verse alignment. No approved reconstructed BHH Bible is claimed.

[BHH source library](bhh.html) opens the full local ETCBC/DSS index: 500,995 source units under 997 source labels, with fragment/line locators and sign-level reconstruction, uncertainty, correction and removal annotations. Labels include composite and non-Qumran material. All units remain separate; this is not a synthetic DSS Bible. Orange flags reconstructed material; exact annotation arrays remain visible. The view includes paged filtering, source downloads and independent verified offline saving.

Four complete STEP TAHOT source files, 24 structured MAM book-group files, THB Hebrew/Greek lexicons and a research versification map are available as compressed source readers. The STEP files explicitly retain editorial retroversions/alternatives. THB/QDR are interfaces to overlapping primary sources, not independent witnesses. Existing WLC, Swete and STEPBible word-study resources are reused. All nine related repositories have a source entry and an honest import/availability explanation. DDHB publishes no ready corpus in its inspected tree; Tehillim is bounded research; the unlicensed modern Ginsburg digital edition is not redistributed.

The MAM converter dispatches known roles and fails on unknown types; it chooses combined cantillation once, keeps ketiv and qere, omits note prose/repeated endings from scripture, preserves exceptional letter text, and supplies separators/inverted nuns/implicit maqaf. Raw structured files retain distinctions simplified for display. This does not constitute complete Masorah commentary or a full MAM representation.

The build uses a normalized SQLite authoring database with FTS5 outside the publication tree, exports bounded gzip packs with SHA-256 manifests and reuses all previous payloads. Source input hashes and 32 Git blob identities are recorded. New text packs total 2,749,919 compressed bytes and DSS packs 11,771,676 bytes; the complete release size is reported after verification. Private user data/storage names and earlier release URLs remain intact. No automatic approval of scholarly conjectures or platform permissions is implemented.
