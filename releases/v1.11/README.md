# Reader 1.11 — Hungarian and Estonian Uralic expansion

46 public editions. Adds Hungarian Károli 1908 (66 books / 31,126 nonempty numbered source units) and the supplied Estonian Piibel Kõigile snapshot (Matthew, Mark, Luke, John and Romans only / 4,212 units). The Hungarian source also has 44 empty placeholder records; these are omitted from display and retained in the raw source. It uses Calvin versification. Independent source panels retain each edition’s reference numbers; no verified cross-versification alignment is claimed.

Hungarian Károli 1908 is Public Domain, verified in both the source declaration and HunKar module 2.0 configuration. Estonian Piibel Kõigile is © 2023 Sihtasutus Piibel Kõigile, CC BY-SA 4.0. Its supplied USFM snapshot is partial, despite the broader project’s Bible title. Display extraction omits headings and footnotes, preserves spelling and accents, and is shared under the same CC BY-SA 4.0 without implying publisher endorsement. Exact raw sources, copyright information, checksums and derived UTF-8 USFM are available under sources/.

The unrelated SWORD Est module was excluded because its copyright status is unknown. It is not labeled as a verified 1914 edition. The historical Estonian scan and broader Uralic languages remain acquisition candidates, not installed text claims.

Use **Uralic languages** to open a Hungarian/Estonian/Finnish comparison, or use the directory. Finnish and Estonian have the Finnic browsing branch, Hungarian its own Uralic branch. This is not a claim of mutual intelligibility or a UBS provider classification. All four optional slots, favorites, indexed search and selected-text offline saving remain supported. No pronunciation reconstruction or new matching audio is claimed; existing audio choices remain independent.

1.11 deliberately reuses the unchanged 1.10 IndexedDB schema and source-version keys. On the same origin/browser storage, permitted private LLL/KR92/RK imports and previously saved texts remain available without copying or reimporting. The service worker and app shell have their own 1.11 scope/cache and do not replace earlier readers. A separate browser/device or isolated installed-app storage still needs its own permitted import. Personal files are not bundled or uploaded. Keep the original file because browser storage can be cleared or evicted.

Biblia 1776 data and source downloads are shared from 1.10; other established extra texts are shared from 1.8. New bulk files contain only the two new editions. Worker navigation fallback is limited to the actual reader/directory routes so source ZIP downloads and other documents are served as their own files. Audio, publisher sites and raw source downloads require internet. The explicitly labeled 1.8 ZIP remains the legacy file-open reader; there is no new 1.11 ZIP.

Tested in Chromium: real Hungarian/Estonian/Finnish text, accent-preserving search, Uralic directory and explicit missing-book behavior, full 66+5 offline saving/reload, valid source ZIP download with the worker active, all 16 slot states and existing themes/mobile/storage behaviors, and a real private LLL import in 1.10 followed by offline reopening in 1.11. Physical phone installation and Safari/Edge execution are not tested. Broader Sámi/Karelian/other Uralic coverage and edition-matched audio remain pending source/license verification.
