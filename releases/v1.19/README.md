# Reader 1.19 — aligned verses, gzip compatibility and Japanese reading aids

Verified staged increment; included in the following 1.20 reader. The root still opens 1.18 until 1.20 publication.

Aligned verse rows are the default for every installed translation. On wide screens, all selected texts share one grid row per source verse label, sized by its tallest cell. Narrow screens group each verse’s selected texts together. Independent source chapters remain an explicit choice in Settings. This aligns labels and layout, not the meaning of different versifications: Septuagint/Psalms and other source traditions can number the same content differently. Ranges, absent verses, zero/letter references and original source bundles are retained.

KR33/38 native inline verse labels within the same source chapter are separated into display rows instead of aligning their enclosing storage-row offsets. Original bundles, source fingerprints and saved quotations are unchanged. New aligned bookmarks retain native-reference identity; old source-reference bookmarks and search hits resolve through the display adapter. For the eleven source books with cross-chapter inline markers, the whole book retains its original source keys until a verified chapter map exists; no text is moved between chapters. Text 1 note quotations follow the displayed native labels in aligned mode and the original row positions in explicit source mode.

Gzip packs now use native DecompressionStream when available and bundled Pako 2.1.0 when missing or unusable. Both paths keep bounded expansion, expected length, SHA256/source checks; damaged data is never displayed. The decoder and licenses are cached with the app shell; no CDN dependency. Existing Nordic/Japanese packs and source archives are reused from 1.18. Original texts, private imports and notes stay in the existing device stores.

Settings → Reading appearance → Japanese kana above kanji enables experimental dictionary-derived ruby annotations for the installed historical Japanese source. This is an original implementation inspired by PRS’s kana presentation, not copied publisher furigana. All 31,099 source rows have separate token packs; token originals reconstruct the source exactly. Historical/contextual/name readings may be wrong; linguistic review remains pending. The original text and existing Latin forms remain available. Copies and notebook exports omit kana annotations. Visible kana forms participate in search; fallback/original search remains available when reading packs are missing. Save selected texts also saves optional kana packs when enabled; removal clears them separately from the existing Latin aid cache.

Study → Reading tracker manually tracks source chapters for each Text 1 edition. Opening, listening and scrolling never mark a chapter read. Progress stays on this device. Study → Listening & resources provides 11 PRS language/script groups and distinguishes external modern revisions from installed historical/open editions. The links require internet; no PRS text/audio or proprietary app code is copied. See [research](../../docs/research/prs-assessment-119.md).

Public catalog remains 62 editions. Modern Japanese Shinkaiyaku 2017 is an external PRS link, not a newly redistributed Bible. Complete Estonian OT, additional translated guides, verified spoken forms and physical Safari/Edge testing remain open. New source packs are small and reuse prior corpora; further large corpora still need separate hosting.
