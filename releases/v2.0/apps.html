Reader 2.0 — browser or Rust app

Detecting environment…

The web reader remains available. The Rust app is a separate installation with its own storage origin. Existing browser notes, bookmarks and saved texts are not deleted or silently copied. Export supported Notes/vocabulary backups before moving and import them explicitly in the app.

Windows PC

Tauri 2 with a Rust core and Windows WebView2. A Windows installer is produced by the project build when its checks pass. Unsigned review builds are distinct from a signed public release.

Mac

Separate Apple Silicon and Intel builds. The app uses the system WKWebView and Rust core. Signing/notarization and installation require their own release process.

Android phones and tablets

Optional Rust/Tauri Android app, alongside browser/PWA reading. The Android test package is not an automatic update or a Google Play publication.

iPad and iPhone

Optional Rust/Tauri iOS target. Simulator verification does not make an installable iPad release. Physical-device signing/provisioning and App Store/TestFlight distribution require a developer account and separate authorization.

Build status and review artifacts · Build, storage and verification notes

Browser environment detection is a hint; desktop-mode iPad browsers can resemble a Mac. In the installed app the Rust build target supplies the OS and architecture. No device identifier is collected.

Version 1.29 remains reserved for its separately prepared improvements. Reader 2.0 does not invent or overwrite that package.
