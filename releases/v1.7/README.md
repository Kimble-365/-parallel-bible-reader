# Reader 1.7 — first global expansion

35 installed editions: retains 1.2–1.6 and adds French Louis Segond 1910, Spanish Reina Valera 1909, Russian Synodal, Chinese Union Version Traditional, Arabic Van Dyck and Open Bislama Revised. All six have 66 canonical books. Copyright declarations and original USFM archives come from the verified official Scripture App Builder 14.7 distribution. Unspecified-license resources and the NC-ND Tok Pisin resource were excluded.

The directory represents Europe, Africa, Asia, Russia, China, Australasia, South America and North America through actual installed languages and their indicative geographic associations. This is not comprehensive coverage of those regions or their Indigenous languages. Uralic has Finnish; further Finnic, Sámi and other Uralic resources remain a documented acquisition queue, not installed placeholders.

Written Latin uses ICU 76 for Cyrillic, Han and Arabic. Chinese readings can be contextually wrong; Arabic unwritten vowels are not inferred. None is a spoken-language reconstruction. Chinese search allows a single Han character, with exact-substring matching; longer queries use the bounded trigram index. The authoring SQLite database indexes all 778,240 installed verse records; the static browser uses its own lazy indexes.

Bislama Zechariah 4:10 has two source units sharing one number. Both are displayed in order together, with an explicit notice; the exact source units remain in USFM. Source bridges are retained.

Existing 30 verified audio choices remain. New language recording candidates could not be verified because the external catalog returned HTTP 522; no unverified recording IDs were installed. Text and audio are independent and may use different translations. See sources/global-audio-checks.json.
