# Reader 1.8 — Hebrew and Septuagint source references

43 installed editions. Eight additions: Westminster Hebrew/Aramaic (39 books), historical Delitzsch Hebrew NT (27 books / 260 Wikisource source pages), Vamvas 1850 Greek (66), Swete Old Greek (52; Ecclesiastes absent), Theodotion Daniel/Susanna/Bel (3), French Giguet LXX (54), Church Slavonic Elizabeth Bible (76), and partial English Thomson LXX (11 completed source files). Counts describe supplied nonempty source books, not an asserted common canon.

Swete and Delitzsch are CC BY-SA 4.0, Westminster CC BY 4.0; the other imported texts have retained public-domain declarations. Exact raw archives, revision attribution, checksums and derived UTF-8 USFM are included under sources/. The 159,764 new source units use a separate SQLite table and FTS index with opaque verse keys; production integer-verse records remain unchanged.

Independent source panels are automatic for these editions. Each panel has its own chapter selector. Preserve Esther prologue, Odes iva/ivb and verse keys such as 59a, 35I and 1a1. Shared URLs, bookmarks and search preserve source keys. This does not claim a verified verse alignment. Optional comparison by numbers is explicitly unverified. Derived USFM maps mixed chapter keys and chapters containing nonnumeric verse keys to sequential numeric references with source-key rem markers; raw archives and reader retain original keys.

Written Latin comes from ICU 76 and is not a spoken reconstruction. Historical Hebrew is not modern conversational Hebrew. Delitzsch’s Wikisource source has numbering defects: unnumbered opening passages are retained as 0, and missing source verses are not filled. See the source library for details.

Modern Hebrew NT: external Haktuvim reading link; latest revision and redistribution/adaptation rights still require verification. Do not confuse this with the installed historical Delitzsch. Brenton English: external CCEL reading link; a clean structured source was not acquired, and flattened JSON with embedded footnotes was rejected. French Giguet and historical Church Slavonic add non-English Septuagint options. New matched audio recordings have not been verified; the earlier 30 independent recording choices remain.

Production root unchanged. Download the offline reader from the v1.8 GitHub prerelease, extract the entire ZIP, and open index.html. No account, build step or Biblical Encyclopedia required. Development ZIPs live as release assets to keep the Pages site below its size limit.
