# Reader 1.5

Adds 39-book Biblical Hebrew/Aramaic OT source (23,145 numbered records) and 27-book Koine Greek NT source (7,958 numbered records), with ICU orthographic Latin. These are original-language sources, not modern translations. Source verse numbering, pointing and Greek accents are retained in the displayed original; notes, morphology and alternate numbering are available in the preserved USFM archives under sources/. No specific spoken reconstruction is claimed.

All visible forms have a bounded, lazy per-book Unicode trigram index for repeated substring searches. New texts also have authoring SQLite FTS5 indexes. The browser remains static and account-free; it does not require SQLite/WASM or a backend.

The directory now distinguishes ancient Hebrew/Aramaic and Koine Greek. Wider European/Uralic and global candidates are documented in the project research plan; they are not marked installed.

See LICENSES.md and sources/ for attribution, source licenses, manifests and archive hashes.
