# Parallel Bible Reader 1.2

A separate development release. Production remains at the repository root.

Four numbered text slots each offer None. Any subset can be selected, including all empty. Slot numbers remain fixed. Books, chapters and search coverage follow the union of the selected texts. Search checks only displayed text forms and identifies slot, edition and form. Repeated selections remain separate slots. Results are capped at 100 per search in this release; corpus-wide indexing and paging are later increments.

Preferences migrate from the original three-selector reader into a separate v2 reading-state key. Old production preferences are retained. Shared links preserve all four choices, including empty slots. Bookmarks use an edition with actual verse text; selecting a bookmark whose edition is not displayed opens it in a free slot (or replaces slot 1 when all four are occupied).

Download parallel-bible-reader-1.2.zip, extract it entirely and open index.html. Audio is external and not bundled. Text and audio can be different editions. See LICENSES.md in the ZIP and the in-app source notices.
