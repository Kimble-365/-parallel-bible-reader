# Reader 1.3

Builds on 1.2. Compact dropdowns contain curated popular translations, user favorites and the current choice. “Browse all translations” opens a dedicated catalog with native-name/alias/ISO lookup and combined family, language, script, continent, country and Indian-state filters. Choosing an edition changes only the requested numbered slot.

Only the existing 27 installed editions are selectable. Classification and geography metadata support browsing and are not claimed to be UBS genealogical records or exhaustive language territories. Provider mappings remain separate. Favorites are stored locally.
